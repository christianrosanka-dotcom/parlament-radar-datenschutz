Datenschutzerklärung für Parlament Radar

Stand: 12. September 2026

2. Zweck der Anwendung

Parlament Radar erstellt aus öffentlich zugänglichen Informationen über Vorgänge des Deutschen Bundestages verständliche Inhalte für ein Instagram-Karussell. Die Anwendung wird ausschließlich vom Betreiber für das eigene Instagram-Business- oder Creator-Konto verwendet.

3. Instagram- und Meta-Daten

Für die Veröffentlichung ruft die Anwendung über die Meta Graph API die erforderlichen Kontoinformationen ab. Dazu gehören insbesondere die Instagram-Konto-ID, der Benutzername und technische IDs für die Erstellung und Veröffentlichung von Medien.

Die Anwendung liest keine privaten Nachrichten, keine Kommentare und keine Daten fremder Instagram-Konten. Sie veröffentlicht ausschließlich Inhalte auf dem vom Betreiber autorisierten Instagram-Konto.

4. Access Token

Der Meta-/Instagram-Access-Token wird als vertrauliches GitHub-Secret gespeichert und nicht im Quellcode veröffentlicht. Er wird ausschließlich zur Authentifizierung gegenüber der Meta Graph API verwendet. Das Instagram-Passwort wird von der Anwendung nicht gespeichert oder verarbeitet.

5. Verarbeitete Inhaltsdaten

Die veröffentlichten Texte und Bildkacheln werden aus öffentlich zugänglichen Bundestagsdaten erzeugt. Zur Formulierung der Texte können diese öffentlichen Sachinformationen an den beauftragten Dienst OpenAI übermittelt werden. Private Nachrichten, Passwörter oder private Instagram-Inhalte werden nicht an OpenAI übermittelt.

6. Hosting der Bilddateien

Die für Instagram erzeugten PNG-Bildkacheln werden vorübergehend in einem separaten öffentlichen Cloudflare-R2-Bucket gespeichert, damit die Meta Graph API sie abrufen kann. In diesem Bucket liegen ausschließlich die erzeugten Bilddateien und keine Datenbank oder Zugangsdaten.

7. GitHub Actions

Die automatisierte Ausführung erfolgt über GitHub Actions. Zugangsdaten werden dort ausschließlich als verschlüsselte Secrets verwendet. Die Anwendung speichert keine Zugangsdaten im Repository.

8. Speicherdauer und Löschung

Die Bilddateien werden nur so lange benötigt, wie sie für die Verarbeitung und Veröffentlichung des jeweiligen Instagram-Beitrags erforderlich sind. Eine Löschung oder Auskunft zu den von dieser Anwendung verarbeiteten Daten kann jederzeit per E-Mail angefragt werden.

Bitte richte Anfragen an wsut12@yahoo.de.

9. Änderungen

Diese Datenschutzerklärung kann angepasst werden, wenn sich die Anwendung oder die verwendeten Dienste ändern. Es gilt jeweils die auf dieser Seite veröffentlichte Fassung.
